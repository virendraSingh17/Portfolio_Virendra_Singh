# Virendra Singh — Animated Portfolio

A modern single-page frontend portfolio built with only HTML, CSS and JavaScript.

## Run
No npm or Node.js is required.

Open `index.html` directly in your browser, or use VS Code Live Server.

## Included
- Animated hero section
- Glass/code-card visual
- Moving skills ticker
- Scroll reveal animations
- Interactive skill cards with 3D tilt
- Animated project visuals
- Dark/light theme
- Responsive mobile navigation
- Custom cursor on desktop
- Animated background grid and glowing orbs
- Contact form using mailto
- Responsive mobile/tablet/desktop layout
